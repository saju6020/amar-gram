# Store front — UX

The clickable design for the Amar Gram customer website, in the chosen theme (ripe mango & banana leaf,
owner, 2026-10-24). Open [`index.html`](index.html) in a browser (double-click works, or serve
`docs/design` and visit `/store/index.html`).

## The theme

| Token | Value | Used for |
|---|---|---|
| Page | `#FBF3E2` | Warm ripe-banana cream background |
| Surface | `#FFFAF0` | Cards, panels |
| Primary | `#B4531A` | Papaya: main buttons, links |
| Highlight | `#EDA73A` | Mango: Add buttons, badges, the hero's harvest card |
| Leaf deep | `#3F6A1E` | Top strip, logo badge, growers band, selected states |
| Leaf light | `#E3EDC6` / `#E6EFC9` | Hero band, selected options, success messages |
| Leaf text | `#557A1F` | Origin labels, "Certified organic" |
| Ink | `#2A1F12` / muted `#69553C` | Text |
| Type | Fraunces (display) + Work Sans (body) | |

## The screens

| File | Screen |
|---|---|
| `Home.dc.html` | Shop home |
| `Catalogue.dc.html` | Category & search results with working filters |
| `Product.dc.html` | Product page |
| `Checkout.dc.html` | Desktop checkout and confirmation |
| `BasketPhone.dc.html` | Phone basket and checkout |
| `HomePhone.dc.html` | Phone shop home |
| `SignIn.dc.html` | Sign in and create account |
| `Account.dc.html` | My account overview |
| `MyOrders.dc.html` | My orders, tracking and returns |
| `MySubscriptions.dc.html` | My subscriptions |
| `Profile.dc.html` | Profile, addresses, notification choices and privacy |

Photos are placeholders; prices are sample figures; facts still to come are in `[BRACKETS]`. Payment
methods follow the SRS v3.0 scope: cash on delivery, bank transfer confirmed by staff (and card on the
in-store terminal for counter sales). There is no online payment gateway in v1.
